## Semantics

The function reads `ICC_PMR_EL1`, writes its low 32-bit value XOR `0xe0` back
to the same register, immediately restores the original register value, issues
`DSB SY`, reads `TPIDR_EL2`, and falls through directly into
`__fswab32_0`. Its semantic result is therefore the byte-swapped low 32 bits of
`TPIDR_EL2`.

The temporary priority-mask mutation has no directly established purpose. It is
recorded literally rather than treated as a standard interrupt-disable API.
