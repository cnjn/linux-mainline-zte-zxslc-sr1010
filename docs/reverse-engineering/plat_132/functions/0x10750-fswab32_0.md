# 0x10750 __fswab32_0

## Status

- Status: complete
- Confidence: verified.
- Size: `0x8` bytes, 2 ARM64 instructions.
- Recovered signature: `u32 __fswab32_0(u32 value)`.

## Semantics

The function executes ARM64 `REV W0, W0` and returns, reversing the byte order
of its 32-bit argument. It has no global access, lock, allocation, callback,
or error path.

## Caller Context

Observed callers are `sub_10738`, `can_tcp_gro`, `pp_tcp_gro_flush`, and
`pp_net_tcp_gro`; the latter uses it only in debug logging paths. GRO parsing
uses this helper for network-order 32-bit fields.
