## Semantics

Programs two XMAC EEE-related words. XMAC selectors exactly `2` and `3` use
absolute low-address windows:

| Word | XMAC 2/3 address |
| --- | --- |
| control | `((xmac + 7) << 16) + 0xd0` |
| timing | `((xmac + 7) << 16) + 0xd4` |

Every other byte selector uses NPPT-relative addresses
`nppt_base + (xmac << 18) + 0x140340` and `+0x140350` respectively.

The control word is read once. A byte `enable` value exactly equal to one sets
control bits `0x000b0000` and writes timing word `0x03e80020`. Every other value
clears those control bits with mask `0xfff4ffff` and writes `0x03e80000`.
There is no range validation, lock, barrier, or semantic return value.
