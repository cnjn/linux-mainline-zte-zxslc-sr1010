## Semantics

Reads `TPIDR_EL2` and discards its result. It then reads `ICC_PMR_EL1`, writes
the low 32-bit value XORed with `0xe0`, restores the original priority-mask
value, and executes `DSB SY`.

The final instruction is immediately followed by `sipc_init @ 0x165b8`; there
is no branch or `RET` in this entry. Control falls through into `sipc_init`,
which writes zero to `nppt_base + 0x4000` and returns zero. The recovered C uses
`return sipc_init()` to represent that tail fall-through.
