Patch 0012: net: ethernet: zte: add ZX279133 NPPT Ethernet

Scope:
- drivers/net/ethernet/{Kconfig,Makefile}
- drivers/net/ethernet/zte/{Kconfig,Makefile}
- decomposed ZX279133 main/TM/NP/IDM/MAC/netdev sources and private headers
- WAN eth0 only; no LAN conduit, DSA, switch source-port or private-VLAN policy
- MAINTAINERS

Changes:
- add the ZX279133 NPPT/XMAC1/IDM Ethernet driver as a composite object rather
  than the former 6500+ line monolithic source
- retain zx279133_hardware_prepare()/unprepare() as the ordered lifecycle
  coordinator while splitting TM, PPU/SPA/NPPU, IDM, MAC/XPCS and netdev code
- use coherent DMA ownership for active TX/RX descriptor and free-ring memory
- validate the complete IDM reserved-memory window through free ring 4 with
  overflow-safe 32-bit DMA-range checks
- propagate all XPCS C45 access errors, preserve original negative poll errors,
  and fail closed if the post-enable SGMII VEND2 reapply fails
- initialize the MAC/phylink interface from standard DT phy-mode and leave
  dynamic SGMII/2500BASE-X selection to ZX279051 PHYLIB read_status()
- deliver RX directly to eth0 and submit TX to the validated WAN destination
  port 6; no later RTL8372N transport contract is present
